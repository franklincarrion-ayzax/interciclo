Cloud Computing y Virtualización

Cloud Computing

Modelo que permite el acceso bajo demanda a través de Internet a recursos informáticos compartidos y configurables (servidores, almacenamiento, redes y servicios).

SaaS (Software as a Service)

Aplicaciones alojadas y administradas completamente por el proveedor en la nube, accesibles desde el navegador web (ej. Google Workspace, Microsoft 365).

PaaS (Platform as a Service)

Entorno listo para desarrollar, ejecutar y gestionar aplicaciones sin administrar la infraestructura física ni el sistema operativo subyacente.

IaaS (Infrastructure as a Service)

Provisión de infraestructura virtualizada (máquinas virtuales, almacenamiento y redes) donde el usuario controla el sistema operativo y sus aplicaciones.

Virtualización

Tecnología que mediante un hipervisor crea versiones virtuales de hardware para ejecutar múltiples sistemas operativos aislados en un mismo servidor físico.

Docker

Plataforma que empaqueta aplicaciones y todas sus dependencias dentro de contenedores ligeros y portables que comparten el kernel del sistema anfitrión.
